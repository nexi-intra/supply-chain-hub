Supply Chain Hub 1.5.8 improves the daily dashboard, shift schedule, guide previews and Arcade.

- A person's daily shift comment now appears consistently on all their tasks and only once in team status. The schedule keeps today's date aligned as tasks load.
- A personal toggle hides unassigned tasks from “Team opgaver i dag” without deleting or changing the tasks.
- Home-office patterns can repeat at different weekly intervals for each chosen weekday.
- Original Word guides remain viewable as PDF inside the app, now using locally installed Microsoft Word rather than LibreOffice. The preview header is smaller so more of the guide is visible.
- Arcade supports Space/Enter to retry, fixes Chickeninvasion replay and Nexi Flyer input, and improves Brick Break's width, levels and bomb-ball transition.

The GitHub ZIP is a local Windows app package; publishing it as an in-app update on the shared drive is a separate step. Microsoft Word is required on a computer when an original-layout DOCX guide needs conversion and no saved PDF preview exists.
